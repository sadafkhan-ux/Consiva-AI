# Scan session logs

One directory per website scan, named `scan-YYYY-MM-DD-HHMMSS-<scan-id>/` (Asia/Kolkata), holding the files listed in the master requirements: session summary and timeline, discovered URLs, page results, cookie inventory and observations, token, storage and network observations, errors and retries, evidence index, and the final scan report.

Not implemented yet. No scan has produced these files. Development logs live in `docs/development-logs/` and development reports in `docs/development-reports/`; the three are kept separate.
